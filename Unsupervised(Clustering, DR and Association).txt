##Unsupervised Learning
Where the algorithms are trained on unlabeled data.
Types:
1.Clustering:
Divide set of data points into multiple cluster based in the similarity. It aims to segregate the data points with similar traits.

2.Association:
Finds the relationship between the variables in large datasets. Determine the dependencies of one data item over another data item. Applications like market basket analysis, FP Growth, Apriori Algorithm etc. 

3.Dimensionality Reduction:
Identifies the pattern in a dataset and simplifies it by reducing the dimensionality(number of features while preserving its structure and relationship) of the data.
